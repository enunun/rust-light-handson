# テストリスト

## 単体テスト

### oid

- [x] 20バイトの値は，1バイトあたり2桁の小文字の16進数で表示する(`to_hex`のテストを移す)
- [x] `short`は先頭の7桁を返す
- [x] 40桁の16進数から作った`ObjectId`は，同じ40桁で表示する
- [x] 大文字の16進数からも，小文字と同じ`ObjectId`を作る
- [x] 4桁の文字列は，長さ4の`InvalidLength`になる
- [x] 41桁の文字列は，長さ41の`InvalidLength`になる
- [x] 40桁目が`g`の文字列は，位置39と文字`g`の`InvalidChar`になる

### object

- [x] 空のデータと`hello\n`のハッシュのテストを，`to_string()`の結果と比べるように変える
- [x] `to_hex`の2つのテストを消す(`ObjectId`の表示のテストに移した)

## 結合テスト

### hash_blob

- [x] 2つのテストを，`to_string()`の結果と比べるように変える

### object_id

- [x] `hello\n`のIDは，40桁で表示でき，7桁に短縮でき，大文字の40桁から作ったIDと等しい
- [x] `ce01`は，長さ4の`InvalidLength`になる
