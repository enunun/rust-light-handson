# テストリスト

## 単体テスト

### tree

- [x] `Mode::Executable`のインデックスの数は`0o100755`で，`0o100644`から`Mode::File`を作る．知らない数`0o100600`はエラーになる

### index

- [x] 空のインデックスは，ヘッダー`DIRC`，版2，エントリーの数0と，そのSHA-1のチェックサムからなる
- [x] `hello.txt`のエントリーは，62バイトの固定部，パス，1個のNULで72バイトになる
- [x] 3つのエントリーをパスの順に書き，読み戻すと同じインデックスになる
- [x] チェックサムが合わないインデックスは，`CorruptIndex("checksum mismatch")`になる
- [x] インデックスのファイルがなければ，空のインデックスとして読む

### worktree

- [x] 作業ディレクトリの下のファイルを，`.git`を除いて`/`区切りのパスで集める
- [x] 指定したディレクトリの下のファイルだけを集める
- [x] ファイルを指定すると，そのファイルだけを返す
- [x] パスの中の`.`は無視し，作業ディレクトリそのものは空のパスになる
- [x] 作業ディレクトリの外のパスは`None`になる

### repo

- [x] `add`は，指定したディレクトリの下のファイルのblobを書き込み，そのモード，ID，大きさを登録する
- [x] `add`は，実行可能なファイルを`Mode::Executable`で登録する
- [x] `add .`は，作業ディレクトリから消えたファイルをインデックスから除く
- [x] 一致するファイルのないパスの`add`は，`PathspecNotMatched`になる
- [x] `is_under`は，ディレクトリの区切りまで一致するパスだけを当てはめる(`srcs/a`は`src`の下ではない)

## 結合テスト

### add

- [x] `add .`のあとの`ls-files --stage`が，2つのファイルを表示し，`git ls-files --stage`と一致する
- [x] `ls-files`は，パスだけを表示する
- [x] `rgit add`したファイルを，本物の`git status`がステージされたファイルとして表示する
- [x] `git add`で書いたインデックスを，`rgit ls-files --stage`で読める
- [x] サブディレクトリで`add main.rs`をすると，`src/main.rs`で登録する
- [x] 実行可能なファイルは，`git ls-files --stage`で`100755`になる
- [x] 消したファイルは，`add .`でインデックスから除かれる
- [x] 一致するファイルのないパスは`pathspec 'nothing' did not match any files`のエラーになる
