# テストリスト

## 単体テスト

### diff

- [x] 同じ列の編集は，すべて`Equal`になる
- [x] 空の列どうしの編集は空になる
- [x] 空の列からはすべて`Insert`，空の列へはすべて`Delete`になる
- [x] `[a, b, c]`から`[a, c, d]`への編集は`Equal(0, 0)`，`Delete(1)`，`Equal(2, 1)`，`Insert(2)`になる．削除は挿入より前に並ぶ
- [x] `ABCABBA`から`CBABAC`への編集は，変更が5つで最短であり，当てはめると新しい列になる
- [x] 1か所の変更は，前後3つの文脈を含む1つのハンクになり，見出しは`@@ -2,7 +2,7 @@`になる
- [x] 間の一致が6つなら1つのハンクにまとまり，7つなら2つのハンクに分かれる
- [x] 見出しは，要素が1つなら数を省き，0なら直前の行の番号を書く(`@@ -0,0 +1 @@`，`@@ -1,2 +1 @@`)
- [x] 変更がなければハンクはない

### patch

- [x] 変更したファイルは，`index`の行(IDとモード)，`---`と`+++`の行，ハンクを持つ
- [x] 追加したファイルは`new file mode`を，削除したファイルは`deleted file mode`を持ち，ない側は`/dev/null`になる
- [x] 空のファイルの追加には，ハンクも`---`と`+++`の行もない
- [x] 末尾に改行のない行の後ろに`\ No newline at end of file`を書く
- [x] モードだけが変わったファイルは，`old mode`と`new mode`の行だけを持つ
- [x] NULを含むファイルは`Binary files … differ`になる(追加では古い側が`/dev/null`)

### status

- [x] HEAD，インデックス，作業ディレクトリの表を作る関数を，`status`の外に出す(既存のテストは変わらない)

## 結合テスト

### diff

- [x] コミットしたままのリポジトリの`diff`と`diff --cached`は空になる
- [x] 1行を加えたファイルの`diff`は，ノートの例と同じになる
- [x] 変更，2つのハンク，削除，末尾の改行，バイナリー，モードの変更，追跡していないファイルを含む作業ディレクトリの`diff`が，`git diff`と一致する
- [x] 同じ変更と空のファイルを`add .`したあと，`diff`は空になり，`diff --cached`が`git diff --cached`と一致する
- [x] 最初のコミットの前の`diff --cached`が，`git`と一致する
